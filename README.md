# Project Idea Generator (LLM Mini Project)

**Problem:** Students struggle to pick project topics. This app generates 5 project ideas
(with scope, tools, modules, difficulty) from a domain, skill level and available time.

## How to run
```
pip install -r requirements.txt
cp .env.example .env      # then paste your free Gemini key from aistudio.google.com
streamlit run app.py
```

**Stack:** Python, Streamlit, Gemini 2.5 Flash (google-genai).
